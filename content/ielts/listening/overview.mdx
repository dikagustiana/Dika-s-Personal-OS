<Callout>
### Test format

Computer-delivered IELTS. ~30 minutes, with no extra transfer time.
40 questions across 4 audio parts.
Each question is 1 mark, converted to a band score (0–9).
</Callout>

## Format breakdown

| Part | Context | Audio type |
| --- | --- | --- |
| 1 | Everyday social conversation | e.g. booking an appointment, asking for info |
| 2 | Monologue (daily context) | e.g. tour guide talking about a city |
| 3 | Educational conversation | e.g. students discussing a project |
| 4 | Academic lecture | e.g. one speaker explaining a topic in depth |

<Callout>
Audio is only played **once**. You answer on-screen, directly on the computer.
</Callout>

## Types of questions

- Multiple choice (single & multiple answers)
- Matching (e.g. name + description)
- Plan / map / diagram labeling
- Form, note, table, summary completion
- Sentence completion
- Short-answer questions

## Key features of computer-based listening

- Timer on screen shows remaining time.
- Headphones provided; audio quality is usually better than the paper version.
- Highlight function: you can highlight keywords in the question.
- Note-taking: there's a separate box for quick notes.
- Can review and change: click "Next" or use the Review Panel.
- No 10-minute transfer time — you submit answers immediately during the test.

<Callout>
### Tips for computer-based listening

- **No transfer time** → submit your answers while listening.
- **Use the highlight tool** → right-click to mark keywords.
- Spelling is still important.
- **Familiarise yourself with question navigation** → the review screen is useful.
</Callout>

<Callout>
### Avoid these mistakes

- Waiting to review — there's no 10-minute buffer like in the paper test.
- Not checking the timer.
- Getting distracted; audio plays only once.
- Typing too fast with errors.
- Overthinking the highlight function — use it sparingly.
</Callout>
