One of four equally weighted Writing criteria.

## Band descriptor

*Extracted from the Writing Band Descriptor table on the General Information
page — this is the "Task Achievement / Task Response" column.*

| Band | Descriptor |
| --- | --- |
| 9 | Fully addresses all parts of the task with a fully developed answer |
| 8 | Covers all parts well, some minor flaws |
| 7 | Addresses all parts, some underdeveloped ideas |
| 6 | Addresses main points but may miss detail or relevance |
| 5 | Partially addresses the task, limited ideas |
| 4 | Responds to task minimally, may be unclear |
| 3 | Attempts the task, very unclear ideas |
| 2 | Barely responds, fragments |
| 1 | No communication of the task |
| 0 | Did not attempt / completely off-topic |

## What costs marks here

*From the Writing study sheet's common-mistakes list — all three are task
achievement failures rather than language failures.*

- ❌ Giving personal opinions
- ❌ Skipping the overview paragraph
- ❌ Listing data without analysis

The overview is a required element in Task 1: the sheet's four-part structure
puts it second, before either body paragraph. That structure is on the
**Writing Overview** page.
