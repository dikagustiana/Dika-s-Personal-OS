<Callout>
### Test format

3 passages (Academic) / 3 sections (General). 40 questions total.
60 minutes, with no extra transfer time.
</Callout>

## Question types that appear

- Multiple Choice
- True / False / Not Given
- Matching Headings
- Sentence Completion
- Summary / Note / Table Completion
- Yes / No / Not Given
- Diagram Labeling
- Short Answer Questions

<Callout>
### Proven tips and tricks

- **Skim first, scan later** — get the main idea before diving in.
- Highlight keywords in questions and look for synonyms in the passage.
- **Don't overthink T/F/NG** — only answer based on the text, not your opinion.
- Time management: aim for 20 minutes per passage.
- **Don't leave blanks** — there is no negative marking.
</Callout>

<Callout>
### Common reading mistakes

- Reading word-by-word
- Spending too long on one question
- Ignoring keywords and synonyms
- Misinterpreting the question instruction
</Callout>
